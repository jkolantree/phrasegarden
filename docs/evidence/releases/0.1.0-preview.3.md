## Packaging-commit and publication boundary

The containing commit qualifies as packaging commit `P` only if:

1. its sole parent is exact `S2`;
2. it changes only the seven paths in
   `docs/work-packages/PREVIEW-3-PUBLICATION.md`;
3. independent final review binds those exact bytes with zero open P1/P2/P3;
4. `scripts/verify-release-archive.py --require-packaging-commit` passes on
   the committed ZIP, manifest, and ledger.

No public action is implied by satisfying the local packaging-commit checks.
After `P`, fresh remote preflight must confirm a fast-forward `main`, unused
Preview 3 tag and release identity, unchanged Preview 2 rollback, and the
expected Pages target. External publication then requires the separately
confirmed repository, commits, tag, assets, target, and rollback values,
followed by public byte re-download and production smoke verification.
